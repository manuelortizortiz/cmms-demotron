CMMS DEMOTRON - RAILWAY + POSTGRESQL

1) Crea un repositorio en GitHub y sube todos estos archivos.
2) En Railway: New Project > Deploy from GitHub repo.
3) Dentro del proyecto: New > Database > Add PostgreSQL.
4) Railway creará DATABASE_URL automáticamente.
5) El deploy usa: gunicorn app:app.
6) OT, lecturas, compras, bodega y ubicaciones quedan guardadas en PostgreSQL.
7) Puedes migrar después exportando la base PostgreSQL.
8) Si corres local sin DATABASE_URL, usa SQLite en data/cmms_operacion.db.
